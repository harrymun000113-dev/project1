# Comtrade 원본 응답 캐시

Comtrade API 호출이 성공하면 응답 JSON 전체를 전처리 전에 이 폴더에 저장합니다. 파일에는 요청 URL과 파라미터가 포함되며 API 인증 키는 포함되지 않습니다. 동일한 요청은 이 파일을 읽고 전처리를 다시 실행하므로 API 호출 한도를 소모하지 않습니다.

이 폴더를 Git에 추가해 공유할 수 있습니다. 기존에 저장된 Parquet 파일만으로는 원본 API 응답을 복원할 수 없으므로, 원본 JSON 파일은 기능 적용 후 새로 API에서 받아온 요청부터 생깁니다. 원본 데이터를 다시 받으려면 해당 JSON 파일과 대응하는 전처리 Parquet 캐시를 지운 뒤 조회해야 합니다.
