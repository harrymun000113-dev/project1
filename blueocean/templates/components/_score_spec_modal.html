평가기준 (100점 만점)
#지표배점방향데이터 소스

수요 측(시장규모·성장률·트렌드·환율) 합계 50점, 공급 여지 측(한국 점유율·상위3개국·관세율) 합계 50점.

수식 명세

최종 점수 = Σ (정규화 점수 ni × 배점 wi), 여기서 ni ∈ [0, 1].

성장률 항목(3년 CAGR·1년 YoY) — 절대평가
n = clip(g / 30, 0, 1)   # g < 0% → 0점, g ≥ 30% → 만점, 그 사이는 선형
그 외 항목 — 후보 풀 상대 정규화 (P5~P95 클리핑 min-max)
x' = clip(x, P5, P95)
n  = (x' − P5) / (P95 − P5)   # '낮을수록 좋음' 항목은 1 − n

결측 항목은 중립값 0.5로 대체됩니다. 배점표는 blueocean/pipeline/scoring.py의 SCORE_SPEC 하나로 관리되며, 이 모달과 점수 계산이 항상 동일한 값을 씁니다.
